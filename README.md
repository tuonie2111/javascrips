# Interactive Photo Gallery

A simple JavaScript DOM project for practicing `onmouseover` and `onmouseout` events.

## Features
- Hover over any thumbnail to show it in the large preview area.
- The preview text is updated from the image `alt` attribute.
- Moving the mouse away restores the original text and background.
- `console.log()` is included to verify the event, alt text, and image source.

## Files
- `index.html`
- `css/style.css`
- `js/gallery.js`

## Run
Open `index.html` in a browser, or enable GitHub Pages for the repository.

Note: The sample images are loaded from Unsplash URLs, so an internet connection is needed for the images to appear.
